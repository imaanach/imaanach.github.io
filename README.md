## Project Overview

Laundry Pickup Pro is a laundry pickup and delivery service application designed to provide convenient and affordable laundry services.

The application focuses on residents in Maitland, Observatory and Woodstock.

It aims to assist busy working individuals, elderly residents and people living in apartments without laundry facilities.

### Project Objectives

- Provide a convenient laundry booking system.
- Allow customers to schedule laundry collections and deliveries.
- Improve accessibility to laundry services.
- Connect customers with laundromat service providers.
- Provide an affordable and user-friendly solution.

### My Role - Product Owner

As Product Owner, my responsibilities include:

- Organising and prioritising the Product Backlog.
- Identifying important user requirements.
- Ensuring the project focuses on customer needs.
- Supporting the team's overall project direction.
- Helping the team understand project priorities.

## 2. User Stories and Tasks

![User Stories](https://img.shields.io/badge/SECTION_02-USER_STORIES_AND_TASKS-80649D?style=for-the-badge)

### Evidence

User stories describe application requirements from the perspective of the end user.

They help the development team understand what users want to achieve and why specific features are needed.

The following are illustrative examples based on the Laundry Pickup Pro project objectives.

| User Story | Related Tasks |
|---|---|
| As a customer, I want to register an account so that I can access laundry services. | Design registration form, implement authentication and validate user details. |
| As a customer, I want to schedule a laundry collection so that I can choose a convenient pickup time. | Create booking interface, capture pickup information and store booking details. |
| As a customer, I want to track my laundry order so that I can monitor its progress. | Create tracking interface and display order status. |
| As a laundromat owner, I want to manage bookings so that I can organise customer requests. | Create booking management interface and update booking statuses. |
